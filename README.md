# RPG-inventory-system

Practicing typescript in a fun and barbaric way!

<img width="230" height="308" alt="image" src="https://github.com/user-attachments/assets/6c528b80-e079-4764-a7e1-90ada6486335" />

## Features

- Character system
- Item inheritance
- Inventory management
- Weight limitation
- Weapon, Armor, Ring and Potion items
- Health and mana management

## Technologies

- TypeScript
- Node.js

## Running the project

npm install

npm run start

## Concepts practiced

- Classes
- Abstract classes
- Inheritance
- Encapsulation
- Composition
- Method delegation
